## Why

GM 開團前要先有劇本，開房間時也要選一個劇本。分工表把「劇本匯入與管理」「劇本分享／下載其他 GM 的劇本」列為第一階段 ⭐ 功能；設計稿 TV-7 已畫出劇本庫的列表、篩選與分頁。

## What Changes

- 新增劇本庫管理頁（照 TV-7）：每頁 4 個排成一排、卡片／清單兩種檢視、狀態分類（全部／進行中／草稿／已完成，附數量）、規則系統與標籤篩選、關鍵字搜尋、分頁。
- 點劇本卡片彈出詳細資訊視窗（封面、標題、規則／人數／場景數、標籤、簡介、最後編輯時間、編輯劇本）。
- 新增「建立新劇本」與「編輯劇本」表單（基本資料與預計時長，不含場景內容編輯器）、刪除、加星號收藏。表單外觀等設計者交圖。
- 新增匯入／匯出：劇本可匯出成一個檔案，也可從檔案匯入成新劇本（組員問卷 Q3 決定是否延到 12/24 之後）。
- 新增分享：劇本可設為公開分享，其他 GM 在「共用劇本」分類看得到，並能複製一份到自己的劇本庫（組員問卷 Q3 決定是否延到 12/24 之後）。

## Capabilities

### New Capabilities

- `script-library`: 劇本的列表、篩選、搜尋、詳細資訊、建立、編輯、刪除、收藏、匯入匯出與分享複製。

### Modified Capabilities

(none)

## Impact

- Affected specs: script-library（新增）
- Affected code:
  - New: 前端劇本庫管理頁、劇本卡片、詳細資訊視窗、劇本表單
  - New: 後端劇本 API 與劇本資料表、封面圖片上傳
- Dependencies: project-foundation（Script 型別、頁面外框）、account-auth（劇本擁有者）。room-lobby 建立房間時會從這裡選劇本，房間大廳顯示劇本的預計時長。
